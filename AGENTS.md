# Agent Workboard repository instructions

Read [`plans/PLANS.md`](plans/PLANS.md) before creating, changing, or executing an Epic, Feature, or Work item.

While Workboard is still bootstrapping its own planning and publication workflow, follow the authority rule in that file. Never hand-edit the live Workboard SQLite database or planning-store repository to repair a failed workflow.

For implementation, work from the dependency-ready item in the current Feature plan. Keep durable progress in Git commits and verification evidence; do not create a parallel `_PROGRESS.md` ledger.
